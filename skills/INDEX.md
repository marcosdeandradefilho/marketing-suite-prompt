## 🎯 Marketing Core (4 skills)

### 1. `copywriting-psychology`
- **O quê:** Gatilhos psicológicos de Cialdini + framework HSO
- **Quando:** Toda copy que precisa vender
- **Saída:** Copy persuasiva com 6 princípios aplicados
- **Tempo:** 5-10 min
- **Combo com:** headline-generator + cta-optimization

### 2. `headline-generator`
- **O quê:** Fórmula "4U" (Useful, Urgent, Ultra-specific, Unique)
- **Quando:** Headlines para landing, email, ads
- **Saída:** 3-5 opções testáveis
- **Tempo:** 2-5 min
- **Combo com:** copywriting-psychology

### 3. `cta-optimization`
- **O quê:** Botões, copy, timing — tudo comprovado
- **Quando:** CTAs que precisam converter
- **Saída:** Copy do botão + email de urgência
- **Tempo:** 3-5 min
- **Combo com:** copywriting-psychology + headline-generator

### 4. `battle-tested`
- **O quê:** Framework de campanha high-ticket (Hormozi)
- **Quando:** Lançamentos de produtos premium
- **Saída:** Estructura completa de venda
- **Tempo:** 15-20 min
- **Combo com:** sales-funnel-script

## 🔄 Pipelines Pré-Configurados

### Para LIVE (Webinar/Masterclass)
```
Dia 1-2: Teaser
  → /headline-generator (curiosity gap)
  
Dia 3-4: Landing
  → /sales-funnel-script (estrutura)
  → /copywriting-psychology (copy)
  → /cta-optimization (botão)
  
Dia 5-7: Email de convite
  → /headline-generator (subject)
  → /copywriting-psychology (body)
  
Dia 8: Live acontece
  → /sales-funnel-script (roteiro de venda)
  
Dia 9-14: Follow-up
  → /cta-optimization (urgência)
  → /authorial-recomposition (humanizar)
```

### Para LANDING PAGE
```
Versão 1: Estrutura
  → /sales-funnel-script

Versão 2: Headlines (A/B test)
  → /headline-generator

Versão 3: Copy principal
  → /copywriting-psychology

Versão 4: CTAs
  → /cta-optimization

Versão 5: Visuais
  → /briefing-de-imagem
  
Versão 6: Social proof
  → /copywriting-psychology (depoimentos)
```

### Para EMAIL SEQUENCE (7 dias)
```
Email 1 (AWARENESS): Problem statement
  Subject: /headline-generator
  Body: /copywriting-psychology
  
Email 2 (INTEREST): Story de transformação
  Subject: /headline-generator (curiosity)
  Body: /copywriting-psychology
  
Email 3 (CONSIDERATION): Social proof
  Body: /copywriting-psychology (depoimentos)
  
Email 4-6 (OBJECTION): Preço, tempo, garantia
  Subject: /cta-optimization (urgência)
  Body: /copywriting-psychology
  
Email 7 (CLOSING): Last chance
  Subject: /headline-generator (urgência extrema)
  CTA: /cta-optimization (timing crítico)
  
Follow-up: /authorial-recomposition (humanizar)
```
