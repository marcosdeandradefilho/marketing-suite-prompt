# copy-estrutura.md — anatomy of a high-converting sales page (BR, 2026)

**Master rule (Hotmart, verbatim):** *"Inverter blocos,
como apresentar preço antes da construção de valor, aumenta fricção e derruba a conversão."* Top captures
attention → middle builds value → bottom concentrates the decision (AIDA across the whole page). **Never show
the price before you've built the value.**

## The canonical block order (long-form that converts)

| # | Bloco | What it must DELIVER | Execution note |
|---|---|---|---|
| 1 | **Headline** | A promise/curiosity that stops the scroll | ~80% of the weight; decides if the page is read |
| 2 | **Subheadline** | Clarity + the COMO (the mechanism), kills skepticism | If the headline is bold/vague, the sub gives clarity. Ambiguity kills conversion |
| 3 | **VSL or welcome line** | Controls the order of the argument | If a VSL: hook in the first 5-10s + a CTA visible near the player |
| 4 | **Dor / identificação** | "Isso sou eu" (PAS — agitate the pain) | The pain needs emotional weight BEFORE the solution |
| 5 | **Mecanismo único (the TURN)** | Why it works THIS time | NAME the method. This is what separates you from "mais um curso" |
| 6 | **Produto em BENEFÍCIO** | What they GAIN, not what it has | "Sai com a 1ª ferramenta rodando" beats "12 módulos" |
| 7 | **Prova social específica** | Perceived probability ("gente como eu fez") | Number + photo + real print, not "ótimo curso!" |
| 8 | **Autoridade (de quem vende)** | Credibility DEMONSTRATED, not claimed | Anti-guru: real students + real artifacts, not a stage |
| 9 | **Oferta + value stack** | Everything included, BEFORE the number | Name each item with its benefit; the total reads bigger than the price |
| 10 | **Ancoragem de preço** | "De R$X por R$Y" + parcelado | "De" only if it's a real price (CDC — see `compliance-br.md`) |
| 11 | **Garantia em destaque** | Risk reversal | Right after the price, human language, a visual seal |
| 12 | **Urgência REAL** | Pushes the decision | Only if true (lote fundador → cheio). Max 1 scarcity surface |
| 13 | **FAQ** | Kills residual objections | ARIA accordion; doubles as objection handler |
| 14 | **CTA repetido (3+ pontos)** | Catches each profile at its moment | After hero, after proof, after offer, after FAQ + sticky mobile |
| 15 | **P.S.** | Catches the skimmer who jumped to the end | The warning + the reminder (Suby) |

A short/warm page can compress 3-8 into fewer sections, but the ORDER never inverts (value before price).

## Awareness map (Schwartz) — the structure CHANGES per audience
Read `fluxo-e-intake.md` §temperature first. **Fatal error: do not try to wake a level-1 reader AND close a
level-5 reader on the same page** (= "genérica pra todos, específica pra ninguém").
- **Warm list (level 3-4, problem/solution-aware):** skip the basics; open at **mecanismo único + oferta**.
  Lighter pain. Lead de Oferta or Promessa. Shorter page.
- **Cold / Meta Ads (level 1-2, unaware/problem-aware):** heavy **pain agitation up top**; name the problem
  before the product; build authority from zero; more proof; more objection-killing. Lead Problema-Solução,
  Segredo, or História. Longer page.
- **Market sophistication:** if the niche has seen many similar offers, the **unique mechanism** has to work
  harder (a named, different "how"); if the niche is fresh, a direct big promise still lands.

## Opening frameworks — pick one for the lead, then AIDA carries the page
- **PAS** (Problema → Agita → Solução): fastest opener, the pain grabs. Short lead, great for warm + cold.
- **PASTOR** (Problema → Amplifica → Solução → Transformação → Oferta → Resposta): carries high-ticket; adds
  the "depois" vision before the offer. Use for long-form / R$1.000+.
- **4 Ps** (Picture → Promise → Proof → Push): persuasion by visualization + proof.
- **StoryBrand**: the customer is the HERO, the seller is the GUIDE (fits anti-guru perfectly — the seller
  never becomes the hero). Great for the "autoridade" block.
- **AIDA**: the backbone of the WHOLE page (atenção no topo → interesse no meio → desejo na oferta → ação no CTA).

## Brunson script by ticket (confirmed in verification)
- **Who-What-Why-How** → free/cheap offers (tripwire, opt-in, short video).
- **Star, Story, Solution** → mid price (≈ R$150–500 / standard VSL): Star (you/the customer) → Story (the
  journey) → Solution (the product).
- **Perfect Webinar (3 false beliefs)** → pitch VSL: list the 3 central false beliefs and destroy each as a
  block. Use this device anywhere on the page to kill objections (the 3 beliefs = vehicle, internal, external).
  Example for a "build tools with AI" product: "preciso saber programar" / "IA é complicado demais pra mim" /
  "já tentei curso de tech e não foi pra frente".

## What each block must actually contain (the checklist when writing)
- **Hero (1+2+optional visual+CTA):** promise understood in <3s, the sub gives the COMO + pra-quem, ONE CTA,
  proof glued near the CTA (logo strip or one strong line). See `componentes-conversao.md` §hero.
- **Dor:** speak the reader's exact internal monologue; concrete daily scenes, not "muitos desafios".
- **Mecanismo:** the named "how" + why it's different from what failed before.
- **Benefício/produto:** transform each feature into an outcome ("o que muda na sua semana").
- **Prova:** specific, dated, odd numbers, real face/print — or a marked placeholder, never invented.
- **Oferta/stack:** list every component with a benefit name + an HONEST anchor value (see `copy-craft.md`
  §oferta and `compliance-br.md` — no invented totals).
- **Garantia:** human language, the real number of days (≥ legal floor), the "sem letra miúda" promise.
- **Urgência:** only the real reason (lote, data, bônus que saem). Max 1 surface.
- **FAQ:** the residual objections, each answered in the reader's voice (see `copy-craft.md` §objeções).
- **CTA + P.S.:** repeated CTAs at pause points; the P.S. restates the core promise + the real deadline.
