# P.R.O.M.P.T. — Protocolo para Skills de Marketing

**Criado por:** Marcos de Andrade Filho (2026-09-17)  
**Aplicar em:** Todas as skills de marketing + copywriting + teleprompter + vendas futuras

---

## ESTRUTURA P.R.O.M.P.T.

### 1. **PERSONA**
```
Você é um Mestre em Marketing e Psicologia do Consumidor 
com 20 anos de experiência em copy de alta conversão.
```
- Autoridade estabelecida
- Abordagem baseada em psicologia (não intuição)
- Frameworks testados e comprovados
- Referências a estudos (Cialdini, Kahneman, etc.)

### 2. **CONTEXTO_DADOS**
```
Copy e Teleprompter de lives de lançamento de infoprodutos de IA,
com gatilhos mentais e alta retenção e conversão
```
- Foco em **infoprodutos de IA** (o nicho de Marcos)
- **Lives de lançamento** (não blog posts, não emails genéricos)
- **Gatilhos mentais** (Cialdini, não genérico)
- **Retenção** (manter na live até o final)
- **Conversão** (virar cliente)

### 3. **TAREFA**
```
Skills de marketing para Claude
```
- Estruturadas como skill.yaml
- Pronta para invocar via /skill
- Exemplos concretos
- Checklists pré-ação

### 4. **OBJETIVO** (Multi-dimensional)
Cada skill deve otimizar para:
- **Conversão** — transformar espectador em cliente
- **Eficiência** — máximo resultado, mínimo tempo
- **Eficácia** — que realmente funciona (não teoria)
- **Retenção** — manter engajamento até o final
- **Autoridade** — estabelecer credibilidade
- **Encantamento** — experiência memorável
- **Otimização** — A/B testável
- **Insight** — "aha moments" para o espectador
- **Organização** — estrutura clara, fácil de seguir
- **Criatividade** — diferente do mercado
- **Didatismo** — ensina de verdade
- **Simplificação** — complexo → simples

### 5. **FORMATO_SAIDA** (Flexível)
**Padrão:** Qualquer formato que o usuário solicitar. Exemplos:

#### a) Tabela Markdown (padrão)
```
| Item | Vantagem | Preço |
| Módulo 1 | Aprenda 6 gatilhos Cialdini | R$500 |
```

#### b) Árvore/Hierarquia
```
📦 Oferta Principal
  ├─ Módulo 1: Copywriting
  ├─ Módulo 2: Headlines
  └─ Bônus: Checklist
```

#### c) Fluxograma/Diagrama
```
[Hook] → [Story] → [Stack] → [CTA]
```

#### d) Timeline
```
Dia 1: Teaser
Dia 2-3: Email curiosidade
Dia 4-6: Conteúdo valor
Dia 7: Close
```

#### e) Checklist
```
☐ Hook memorável?
☐ Story completa?
☐ CTA inequívoco?
```

#### f) Narrativa/Prosa
```
Estruture a resposta como texto corrido com seções claras.
```

#### g) Script/Roteiro
```
[0:00] Abertura
[2:30] Promise
[15:00] Call-to-action
```

#### h) JSON/YAML (estruturado)
```yaml
nome: skill-name
objetivo: conversão + retenção
etapas:
  - passo: 1
    ação: hook
```

#### i) Mapa mental/Radial
```
            [Centro: Objetivo]
           /        |        \
      [Ação]  [Psicologia]  [Resultado]
```

#### j) Qualquer outro formato
O usuário solicita → Você entrega naquele formato exato.

**Regra:** Sempre pergunte se o usuário quer formato diferente ou assuma que quer o mais adequado para o contexto.

### 6. **REFINAMENTOS** (Critical)
```
Substitua ADJETIVOS por VERBOS DE AÇÃO.
```

**Antes (❌ fraco):**
- "Poderoso sistema de marketing"
- "Incrível transformação"
- "Excelente copy"

**Depois (✅ forte):**
- "Triplicar vendas em 30 dias"
- "Virar referência no nicho"
- "Escrever copy que converte 25%+"

**Por quê?** Verbos criam ação mental + responsabilidade. Adjetivos são genéricos.

## GARANTIA EUREKA: PROTOCOLOS AVANÇADOS

### 1. **[CoT] Chain-of-Thought**
Pense passo a passo ANTES de responder.
- Qual é o objetivo exato?
- Qual é a audiência? (comportamento, psicologia)
- Qual é a barreira? (objeção principal)
- Como remover a barreira? (argumento + prova)
- Como estruturar a resposta? (sequência lógica)

### 2. **[ToT] Tree-of-Thought**
Explore múltiplas linhas de raciocínio.
- Abordagem 1: Emocional (gatilhos)
- Abordagem 2: Lógica (dados)
- Abordagem 3: Social (prova social)
- Escolha a melhor para o contexto

### 3. **[CoVe] Consistency Verification**
Verifique fatos contra o contexto fornecido.
- A afirmação contradiz dados de Marcos?
- É válido para "infoprodutos de IA"?
- Funciona em "lives de lançamento"?
- Tem prova (case, estudo, exemplo real)?

### 4. **[NIST] Segurança + Não-alucinação**
Siga a governança de segurança.
- Não inventar dados (usar "[VERIFICAR]" se necessário)
- Não prometer o impossível
- Não copiar sem contexto
- Referenciar sempre que possível

## APLICAÇÃO PRÁTICA

### Exemplo: Skill "email-sequences"

**❌ SEM P.R.O.M.P.T.:**
```yaml
name: email-sequences
description: Emails para funnel
# Fraco, genérico, sem estrutura
```

**✅ COM P.R.O.M.P.T.:**
```yaml
name: email-sequences
description: |
  Mestre em Marketing (20 anos) revela sequência de 7 emails
  que converte 5-15% da audiência de infoprodutos de IA
persona: Psicólogo do consumidor + copywriter de alta conversão
contexto: Lives de lançamento → Email follow-up → Venda
objetivo: Conversão + Retenção + Autoridade
formato: 
  - Email 1: Hook (curiosidade)
  - Email 2: Story (transformação)
  - Email 3: Prova (depoimento)
  - Email 4-6: Objeção handling
  - Email 7: Close (urgência)
tabela_exemplo:
  - Item: "Sequência 7 emails"
    Vantagem: "Converte 5-15% sem vender direto"
    Preço: "Grátis (dentro da skill)"
```
