## 🚀 LIVES DE LANÇAMENTO

Use ESTAS skills nesta ordem:

### 1. **Estruture a live**
```bash
/skill sales-funnel-script
→ Use a estrutura "Perfect Webinar Script" ou "3-Act Launch"
→ Copie o checklist técnico + psicológico
```

### 2. **Crie a headline/promessa**
```bash
/skill headline-generator
→ Use fórmula "4U" (Useful, Urgent, Ultra-specific, Unique)
→ Gere 3-5 opções de headline para testrar
```

### 3. **Escreva a copy da live**
```bash
/skill copywriting-psychology
→ Use "Hook → Story → Offer" (HSO)
→ Aplique 6 princípios de Cialdini (urgência, escassez, autoridade)
```

### 4. **Otimize o CTA da live**
```bash
/skill cta-optimization
→ Botão de acesso deve ter verbo + benefício + urgência
→ Email subject line da live: "Seu acesso expira em 24h"
```

### 5. **Humanize o texto**
```bash
/skill authorial-recomposition
→ Remove tom robótico, adiciona voz pessoal
```

**Pipeline Completo para 1 Live:**
```
1. sales-funnel-script (estrutura)
2. headline-generator (promise)
3. copywriting-psychology (body)
4. cta-optimization (botão + email)
5. authorial-recomposition (polimento)
```

## 💡 DICAS DE OURO

### 1. **Sempre use em PIPELINE, não isolado**
```
Usar só /headline-generator SEM /copywriting-psychology = fraco
Usar /headline-generator → /copywriting-psychology → /cta-optimization = poderoso
```

### 2. **Teste 3-5 variações**
```
/headline-generator pode gerar 5 headlines
A/B teste as 3 melhores
Continua com a que ganhar
```

### 3. **Urgência REAL é 10x melhor que Fake**
```
❌ Fake: "Oferta termina amanhã" (todos dizem)
✅ Real: "Preço sobe quando atingir 100 vendas" (52 vendidas agora)
```

### 4. **Social proof ESPECÍFICO bate genérico**
```
❌ Genérico: "5k clientes satisfeitos"
✅ Específico: "João ganhou R$15k em 30 dias • Taxista de SP • 4.9★ rating"
```

### 5. **Story é 70% da conversão**
```
Use /copywriting-psychology
Conte SEMPRE: Eu era assim → Fiz isso → Virei assim
```
